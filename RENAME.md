# Renaming the product

The name is not decided. Everything below uses the working identifiers. When the name is chosen, change every row, then search the repo for `figma-bridge`, `Figma Bridge` and `REPLACE-ME` to catch anything added since.

**Figma's brand rule:** a product name may not contain "Figma" or "Fig". "<Name> for Figma" is allowed as a descriptor. This applies to the npm package, the plugin name in Figma, the MCP Registry title, the Claude Desktop extension and the Claude Code plugin's display name.

**GitHub owner:** `muradyf` is assumed, not confirmed. `REPLACE-ME` marks every repo-name placeholder.

## Code (one place)

`setup`, `doctor`, `--help` and the MCP prompts read these.

## Outside the repo

- npm: publish under the new name; `npm deprecate figma-bridge-ours "renamed to <new>"` if the old one was ever published.
- MCP Registry: a new `name` is a new entry.
- Users: re-run `npx -y <new>@latest setup` (new plugin folder), re-import the plugin in Figma if the manifest `id` changed, and replace the old server entry in their AI tool.
